DO ZERO AO QR CODE

Escolha seu aparelho.
Depois é seguir os quadradinhos.

O guia foi escrito para quem nunca fez isso. Se você sabe abrir uma pasta, copiar um comando e apontar a câmera do WhatsApp, já está perigosamente qualificado.

1

Instale o Termux certo

Use a versão atual do F-Droid. A versão antiga da Play Store é uma relíquia arqueológica e não serve para esta instalação.

Abrir Termux no F-Droid ↗
2

Prepare o celular e baixe o SHOGUN

Abra o Termux, cole o bloco abaixo e toque Enter. Ele instala o Git e baixa a pasta do bot.

pkg update -y && pkg install -y git
git clone https://github.com/dgreych/shogun.git
cd shogun
3

Deixe o instalador fazer o trabalho chato

Este script prepara as dependências e abre a configuração inicial.

bash scripts/install-termux.sh
4

Ligue e conecte

Mantenha o Termux acordado, inicie o bot e leia o QR com a conta do WhatsApp que será o bot.

termux-wake-lock
npm start

No WhatsApp: Configurações → Aparelhos conectados → Conectar aparelho.

Baixou ZIP? Extraia a pasta, abra o Termux dentro dela com cd caminho/da/pasta e comece no passo 3.
1

Confira os pré-requisitos

Você precisa de Git, FFmpeg, Node.js 20.19+ e npm 9+. Em Ubuntu/Debian, Git e FFmpeg entram assim:

sudo apt update
sudo apt install -y git ffmpeg

Se ainda não tiver Node.js 20.19 ou superior, instale a versão LTS pelo gerenciador recomendado da sua distribuição antes de continuar.

2

Baixe o repositório

git clone https://github.com/dgreych/shogun.git
cd shogun
3

Rode o instalador

Ele faz a checagem da plataforma, instala as dependências do projeto e abre a configuração.

bash scripts/install-linux.sh
4

Inicie e leia o QR

npm start

Depois do QR, mande !menu em um grupo de teste para confirmar que a instância está respondendo.

Baixou ZIP? Extraia, abra o terminal na pasta extraída e comece no passo 3.
1

Instale o básico

Tenha Git, FFmpeg, Node.js 20.19+ e npm 9+ disponíveis no Windows. Depois abra o PowerShell.

GitNode 20.19+FFmpeg
2

Baixe o SHOGUN

git clone https://github.com/dgreych/shogun.git
cd shogun
3

Execute o instalador

Cole no PowerShell aberto dentro da pasta do SHOGUN:

powershell -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
4

Ligue o bot

npm start

Leia o QR no WhatsApp e teste !menu. A janela precisa ficar aberta enquanto o bot estiver rodando.

Baixou ZIP? Clique com o botão direito → Extrair tudo → abra o PowerShell dentro da pasta → comece no passo 3.

ANTES QUE VOCÊ PERGUNTE

Dúvidas honestamente frequentes.

Preciso pagar para usar o SHOGUN?+

Não. O bot é gratuito. Serviços externos opcionais, como capacidades atendidas pela BunnyFy ou hospedagem gerenciada 24/7, podem ter custo próprio.

Preciso de um número separado de WhatsApp?+

É recomendado usar um número dedicado ao bot. Ele conecta como um aparelho vinculado, usando o QR exibido no terminal.

Meu PC ou celular precisa ficar ligado?+

Sim, se você hospedar por conta própria. O processo precisa continuar rodando. Se não quiser manter um aparelho ligado, a hospedagem gerenciada é justamente a alternativa opcional.

Sou iniciante. Vou conseguir instalar?+

O tutorial acima reduz o processo a passos curtos e comandos copiáveis. Você escolhe Android, Linux ou Windows e segue na ordem.

Onde vejo o código e a documentação completa?+

No repositório público do SHOGUN no GitHub, incluindo README, guias de instalação e código-fonte.
