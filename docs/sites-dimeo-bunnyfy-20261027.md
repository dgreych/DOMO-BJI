# DiMeo Family e BunnyFy | GitHub Pages

Publicação independente em pastas do site estático Domo.

- DiMeo Family: https://dgreych.github.io/DOMO-BJI/dimeo-family/
- BunnyFy: https://dgreych.github.io/DOMO-BJI/bunnyfy/

Cada página usa um index.html independente com CSS, JavaScript e favicon embutidos, e og.png para compartilhamento em redes sociais. Não depende de build, Node ou de API privada. Pode ser migrada isoladamente para Cloudflare Workers Static Assets ou Pages com os arquivos desta pasta.

DiMeo: o link da comunidade ainda não foi disponibilizado; o CTA solicita convite pelo WhatsApp comercial. O regulamento detalhado de elegibilidade e antispam ainda depende de publicação pela organização. A premiação anunciada é baseada na atividade, condicionada à meta de membros, e não um sorteio aleatório.

BunnyFy: catálogo institucional. Não abrir tokens, endpoints privados, cadastro, cobrança ou API ao navegador. Implementação técnica de uma função não comprova sua disponibilidade comercial ou operacional. A fonte de verdade para contratos permanece no repositório privado da API.

Preservar a retirada deliberada das páginas Beleza Leal e demais páginas existentes.
